| 3 | 把正整数写成末尾补零的数位序列，检查对角线方法为何不能推出正整数不可数；再证明正整数有限子集的族可数。 | [[笔记主体/书籍/Simon实分析/第一章/知识/可数性与两种对角线方法|可数性与两种对角线方法]]；纸页17（来源 PDF，第 38 页；原文件未公开） |

题 1 的定义多项式必须非零。若允许所有系数都为零，“是它的根”就无法刻画代数数。这里补明必要条件，不把零多项式当成合法的定义方程。

## §1.8 微积分 · 两题

| 题号 | 题意与工作对象 | 关联笔记 / 来源 |
| --- | --- | --- |
| 1 | 迭代微积分基本定理写出多重积分余项，计算相应单纯形的体积，再化为 Taylor 的单积分余项。原式的积分变量与上下限要逐项对应。 | [[笔记主体/书籍/Simon实分析/第一章/知识/Taylor 余项与误差估计|Taylor 余项与误差估计]]；纸页33（来源 PDF，第 54 页；原文件未公开） |
| 2 | 对非负、积分严格为正的权函数，证明积分中值定理，并检查中值点可以选在区间内部的条件。 | [[笔记主体/书籍/Simon实分析/第一章/知识/Taylor 余项与误差估计|Taylor 余项与误差估计]]；纸页33（来源 PDF，第 54 页；原文件未公开） |

题 2 中积分及极值必须存在。使用通常的 Riemann 积分版本时，可采用 $f\in C([a,b])$、$w$ 在 $[a,b]$ 上非负且 Riemann 可积、$\int_a^b w>0$ 这些充分假设。原题仅写开区间上的连续性，却使用闭区间的最小值和最大值，使用前应补清端点条件。

## 原书核校记录

以下记录针对本地 2015 年版。它们是本次文本与公式检查，不冒充作者发布的官方勘误。已确认的问题在正式知识页采用正确表述并说明原因；需要进一步整理题面的问题保留为待核校。

| 位置 | 核校情况与笔记处理 |
| --- | --- |
| 纸页4，开集定义 | 已对照页面：原文量词写 $x\in X$；正确应为 $x\in A$。否则只有整个空间能满足该条件。见 [[笔记主体/书籍/Simon实分析/第一章/知识/度量拓扑与连续性的三种刻画|度量拓扑与连续性的三种刻画]]。 |
| 纸页12，可数次选择 | 不把“普通归纳作可数选择”的说明升级为 ZF 中的一般选择定理。明确区分给定递归规则与一般可数选择，见 [[笔记主体/书籍/Simon实分析/第一章/联系/可数递进与极大性存在证明|可数递进与极大性存在证明]]。 |
| 纸页15，可数并 | 枚举 $(j,k)\mapsto x_{jk}$ 在集合有交或枚举重复时只是满射。知识页通过去重或“可数像可数”完成证明，不依赖其为双射。 |
| 纸页16，基数记号 | 原文把连续统及反复幂集的基数写为相继的 $\aleph$。正式笔记使用 $\mathfrak c=2^{\aleph_0}$，不无条件认定 $\mathfrak c=\aleph_1$，也不把迭代幂集等同于后继基数。 |
| 纸页23–24，复内积 | 作者采用第一变量共轭线性、第二变量线性；上横线须保留。转置 $A^t$ 与共轭转置 $A^*$ 分开。见 [[笔记主体/书籍/Simon实分析/第一章/知识/内积、自伴算子与有限维谱定理|内积、自伴算子与有限维谱定理]]。 |
| 纸页27，习题6 | 题面中的 $Y_j=\{x:N^jx=0,\ N^{j-1}x\ne0\}$ 不含零向量，因此不能直接作为子空间参加直和。题面修订尚待进一步核校，本库不声称已按这些分问完成幂零链证明。 |
| 纸页27–28，习题7 | 下标条件与“上对角矩阵皆幂零”的文字之间有冲突；一般上三角矩阵并不幂零。这里仅按严格上三角的核心目标定位，原题各分问的精确下标仍待核校。 |
| 纸页30–31，式(1.8.2)、(1.8.6) | 已核对页面：关于零点的 Taylor 多项式系数应为 $f^{(j)}(0)$，源文印为 $f^{(j)}(x)$。新笔记使用零点系数。 |
| 纸页31，例1.8.3 | 定义函数中的 $1-x$ 与随后关于 $1+x$ 的展开不一致。知识页统一说明所展开的函数，并把级数截断为多项式的条件写为非负整数指数。 |
| 纸页32，式(1.8.10) | 截断函数的指数式只在 $x>x_0$ 使用，$x\le x_0$ 定义为零；局部支撑包含于开邻域。见 [[笔记主体/书籍/Simon实分析/第一章/知识/光滑截断与有限单位分解|光滑截断与有限单位分解]]。 |
