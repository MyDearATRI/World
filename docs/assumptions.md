# Phase 0 假设、用户任务与未具备资源

本文件冻结本轮决策依据。`NOT_RUN` 表示将来的验证没有执行；`BLOCKED` 表示必须输入缺失。现有笔记阅读能力不能替代形式验证与人类审阅。

## 三类实际任务

| 使用者 | 目标任务                                                                 | 当前可用部分                                                        | 后续验证                                                                                          |
| ------ | ------------------------------------------------------------------------ | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 学生   | 读一段作者证明，定位条件与步骤，尝试修改并看到真实结果，然后恢复原版本。 | 完整笔记、公式、来源、搜索及相关对象阅读；不能在线执行 Lean。       | Phase 4 内容审阅，Phase 5 对齐，Phase 6 真实编辑/恢复；学习效果由 Phase 9H 的真实参与者研究判断。 |
| 作者   | 维护跨来源笔记，核对数学条件、原文步骤和形式证明，辨认失效与替代策略。   | Obsidian 为唯一写作源，网站从批准快照派生对象；正文和维护状态保留。 | Phase 2 版本/证据，Phase 5 多对多映射，Phase 9G 共同演化。不得把编译成功当成作者路线忠实。        |
| 研究者 | 检查依赖、弱化和抽象候选，查看支持证据、预算与失败。                     | 当前引用、结构、原文证明关系可定位；推荐只表示相似。                | Phase 8 有界实验；Phase 9 A–H 预注册与基线。候选失败和搜索耗尽不能变成“不存在证明”。              |

## 非目标与资源限制

Phase 0 不新增 Lean 工具链、数据库、登录、云端推理或在线执行服务，不把私人源库或配置复制到公开目录，也不上传原版 PDF、提示词、模板或维护日志。不组织或冒充真实人类实验，不授予数学创新或形式正确性标签，不把视觉群落称为严格数学 topos。

Master 原文已定位并核对。尚缺可用 Lean 工具链及锁定 mathlib 环境、可验证隔离后端、第二干净环境、人工审阅者和学习研究参与者。当前 GPU 型号/驱动查询不可得；物理手机、屏幕阅读器和跨浏览器矩阵未在 Phase 0 新测。未来预算以 [environment.json](benchmarks/environment.json) 和来源明确的冻结门槛为准，不能看过结果后降低阈值。
