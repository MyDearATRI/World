# Knowledge Topos：独立验收记录

本文件根据用户提供的《KNOWLEDGE TOPOS — INTERACTION AND ARCHITECTURE SPECIFICATION》建立，验收以 Group → Group Action → Representation 为中心的 `/topos.html` 纵向原型。范围是22个概念、67个解释段落与40条有类型关系。原三维地图、文章路由和旧关系图的通过结果不构成本原型的通过依据。

2026-09-10的本地验收已完成。真实 Edge 152.0.4191.66 在1440×1000、1024×900、390×844下操作实际页面、录制WebM，并从视频抽帧检查。最后三段去文字视频的机器检查为48项通过、0项失败；正常界面回归为20项通过、1次后台标签页等待前置异常，调整为读者实际进入新标签页后，独立深链补验4项通过、0项失败。另一位验收人员执行的降级与深链检查为23项通过、0项失败。这些是分别运行的报告，不能拼成一次全量零失败结果，原始失败记录全部保留。

本原型的判断对象是持续存在的知识场。按钮能点击、标签不可见、URL可访问，都不能单独证明场发生了有意义的连续变形。下面的结论结合真实输入、世界坐标轨迹、实际视频帧及数学内容检查；人工结论独立记录，未自动改写机器报告中的 `visualReview.status: pending`。

## 无文字九项人工判断

判断基于实际打开的连续视频抽帧，不只是检查文件存在。验收人员查看了最终三视口每组递归前、递归后和滚入视野后的全部9张帧，并查看每个视口第二次变换的起始与中间帧；此前也查看正常及无字主路径、1440远景/中景/正式解释，以及1024和390的多组连续帧。两位协作者独立复看1440递归三帧，主实施者另查看390嵌套边界。

| 空间行为       | 实际观察与判断                                                                                                       |
| -------------- | -------------------------------------------------------------------------------------------------------------------- |
| focus          | 实心蓝点与更清楚的外环区分当前焦点，正常与去文字模式使用同一几何                                                     |
| neighborhood   | 附近节点和联系更强，外围较淡；不是所有节点同等挤向一个中心                                                           |
| context change | 新焦点获得中心强调，旧中心以淡环保留；能追踪改变来处                                                                 |
| attraction     | 中间帧显示相关节点靠近新中心，世界坐标轨迹亦有连续速度；不只有相机移动                                               |
| recession      | 较弱相关节点向外围和远层退去，原来焦点未突然消失                                                                     |
| emergence      | 新近邻从本来存在的周围场中变得显著，Action与Representation两个阶段方向和邻域不同                                     |
| hierarchy      | 远景可见局部聚合包络及较少主要对象，中景出现更多概念；真实子解释展开并滚入视野后能区分父子阅读边线                   |
| continuity     | 无整场清空或空白切页；22个实体身份延续，坐标、透明度和展开阅读面共同变化                                             |
| semantic depth | 远景分组、中景邻域、形式阅读面、实际子解释是不同内容层次。最终递归补证中，父外线与内缩子线同时出现，焦点与周围场保持 |

最后一项的准确结论是：真实子解释展开并滚动入视野后，可辨认递归阅读层次。1440帧中父线约在x=488、子线约在x=522；390帧中约为x=16与x=43。点击后子解释首先出现在阅读区域下部，并非马上把整屏改成另一种形状。边线表示阅读层次，社区重叠包络表示派生分组，二者都不表示数学集合包含关系。去文字空间行为能被辨认，不意味着无需文字即可解释具体数学关系或证明。

## 方法、复跑与未覆盖范围

`scripts/verify-topos.mjs`只读取原型快照作为诊断，不调用`focus()`、`zoom()`、`setLens()`或`unfold()`代替用户操作。正式操作使用真实鼠标、键盘、滚轮和CDP模拟触摸；物理连续性使用世界坐标与相对距离，相机变化不能单独使其通过。标题回归使用DOM Range真实逐行字形范围，排除同对象内文字及低可见性对象，不把整个块盒子都当作字形。去文字过渡在实际帧采样中同时检查新插入的字段文字。

脚本不构建网站，默认启动现有`public/`的本地`/World/topos.html`；需先完成正常构建。`TOPOS_OUTPUT`选择独立证据目录，避免覆盖历史；`TOPOS_SITE_URL`可指定已发布页面。提供以下入口，每次复跑应另选输出目录：

```powershell
node scripts/verify-topos.mjs --describe
$env:TOPOS_OUTPUT = "topos-new-run"
node scripts/verify-topos.mjs
node scripts/verify-topos.mjs --regressions
node scripts/verify-topos.mjs --references-only
node scripts/verify-topos.mjs --depth-recording
```

实际录制使用现有Edge与Playwright 1.62.1。只下载对应官方FFmpeg build 1011到忽略目录`.cache/topos-browser/`：ZIP 1,411,741字节，SHA-256 `8d08827c019ad36e7b9d49d3648447d884534cb2acf200e71c715f6dd834cc50`。该二进制执行VP8/WebM录制、解码和PNG抽帧，没有安装其他浏览器或修改全局环境。媒体和临时诊断位于忽略目录，不进入正式发布白名单。

尚未运行实体手机、Safari、Firefox、屏幕阅读器或完整辅助技术审计；未测量帧率、GPU耗电和大型知识库性能，也不提供性能评分。这里验证的是22概念原型，不能据此宣布整套教材已迁移到同一交互系统。本文结束时尚未进行该版本线上复查；部署后的验证应另行记录具体提交、地址与真实结果。
