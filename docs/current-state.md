## 可复现的最小入口

在网站根目录已有依赖时，执行以下命令不需要重新导出笔记，也不会上传：

```powershell
node --check scripts/preview.mjs
node --check quartz/bootstrap-cli.mjs
node scripts/preview.mjs
```

现有预览默认监听 `http://127.0.0.1:8081/World/`，停止使用 Ctrl+C。Phase 0 审计使用临时随机端口、完成后关闭，只从 `public/` 读取。本轮 `/`、`/World/`、`/World/atoms/a-000067.html` 与 `/World/library.html` 均返回 200；原子页检查到 MathML。它们是静态启动检查，不替代全页面浏览器验收。

依赖缺失时，沿用 README 中 `pnpm --package=npm@10.9.2 dlx npm ci`；开发为同样入口的 `npm run dev`，端口 8080。本轮未重跑安装命令。不要为 Phase 0 使用 `发布博客.cmd` 或 `预览博客.cmd`：后者调用导出预览流程，会读取源库，超出此次只审计已导出内容的范围。
