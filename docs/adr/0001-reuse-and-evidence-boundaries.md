# ADR 0001：复用现有阅读系统，分开数学事实与显示状态

状态：Phase 0 架构决定。没有安装依赖或实现后续阶段。

现有 Quartz 4.5.2 与 npm 锁文件已经提供源 Markdown、Obsidian 链接、HAST、公式、完整文章及稳定对象地址。知识场的相关性/布局/DOM阅读也已有独立模块。保留它们可以让后续工作集中在目前不存在的形式证据和多对多对齐，而不再维护第二套写作源或发布引擎。[现状与实际检查](../current-state.md)

决定保留 Quartz/Preact、Three.js/DOM 与网站自有 JSON 契约；本轮不迁移 React、Pixi 或 Verso，不新增数据库。后续某个独立编辑区域若需要 React/Monaco，可以按需加载并明确销毁；必须先验证重复进入、缓存、Worker、子路径与阅读降级。选择替代库应基于 Phase 3 的固定场景测量或 Phase 6 的实际接口切片，不能仅因为它较新。

六种图使用共同对象 ID，但不合并语义：Module 是 imports，Declaration 是形式依赖，Proof 是目标/上下文/推理；Structure、Semantic、Pedagogy 分别保存数学结构候选、意义联系和学习顺序。每条关系携带具体来源，不从坐标、反链或模型分数生成形式结论。

正式验证与作者对齐为两套状态。以版本化、追加保存的 Evidence 指向源码、工具链、依赖、公理政策与实际运行；缺证据时保持 UNKNOWN/UNALIGNED。作者证明、AI候选与替代证明均保留各自归属。执行后端与静态阅读分离，实时服务失效不妨碍读原文，也不制造成功诊断。

影响：继续承担当前自有布局与DOM标签的维护成本；暂不获得 Sigma/Graphology 的现成规模优化或完整 Infoview 编辑体验。Phase 2/3/5/6 的有界实测会决定何时有充分理由替换某层。现有 192 对象的浏览成功不外推成百万声明、60编辑场景或研究效果已达标。

原始77节Master现已定位并完成逐节核对；其哈希与映射保存在阶段证据中。当前用户明确要求的主题侧栏是补充入口，不能替代Master要求的连续语境。不能用这份ADR授权扩大源库公开范围或绕过阶段放行。
