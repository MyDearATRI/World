A group is a set $G$ with a binary operation $G\times G\to G$, written $(g,h)\mapsto gh$, satisfying

$$
(gh)k=g(hk),\qquad eg=ge=g,\qquad g^{-1}g=gg^{-1}=e.
$$

The first equality holds for all $g,h,k\in G$; one element $e\in G$ works for every $g$; each $g$ has an inverse in $G$.

组合必须留在 $G$ 内。结合律允许改变括号，不允许交换次序。
